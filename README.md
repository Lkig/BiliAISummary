# Bili AI 总结

Edge / Chrome 扩展：给 B 站视频加 **AI 内容总结**。

支持两条模型通道：**API 直连**，或**经本机 DSH 中转**（复用已授权客户端的额度）。

---

## 一、它能做什么

| 能力 | 说明 |
|---|---|
| **AI 视频总结** | 抓字幕 → 分段理解 → 汇总成「一句话结论 / 核心观点 / 内容脉络 / 关键信息 / 适合谁看 / 避坑提示」 |
| **值不值得看** | 专门有「避坑提示」栏，标题党、广告、注水内容会被直接点出来 |
| **三种深度** | 三档有独立模板，结构完全不同（见下） |
| **无字幕兜底** | ① DeepSeek 语音识别（0.39 元/小时）② 抽帧视觉理解（判断视频类型） |

---

## 二、安装

1. 打开 Edge，地址栏输入 `edge://extensions/`
2. 打开右上角「开发人员模式」
3. 点「加载解压缩的扩展」，选择本目录（`BiliAISummary`）
4. 首次安装会自动打开设置页

> Chrome 同理，用 `chrome://extensions/`。

---

## 三、配置

### 3.0 两条通道

| 通道 | 说明 | 适用 |
|---|---|---|
| **API 通道** | 直连任意 OpenAI 兼容服务商 | DeepSeek、通义、火山方舟等有 Key 的场景 |
| **DSH 通道** | 走本机 DSH 中转 | 复用已授权客户端的额度，不额外花钱 |

两条通道都按 OpenAI 协议调用 `/chat/completions`，切换只改一个下拉框。

#### DSH 通道（本插件的特点）

插件不绑定任何特定的反代工具，只要对方提供 OpenAI 兼容接口即可。
常见的有 [`dsh-connect-workbuddy`](https://github.com/Lkig)、`dsh-connect-trae`、`dsh-connect-ofm` 等。

配置步骤：

1. 在本机启动提供反代的 DSH 插件，记下它的地址（一般形如 `http://127.0.0.1:<port>/v1`）
2. 设置页选「DSH 通道」，填入中转地址与密钥（没有密钥可留空）
3. 点「拉取可用模型」选模型；若该插件不实现 `/models`，会填入内置候选，也可手动输入模型名
4. 点「测试连通性」确认

实测（以 ofm 作为 DSH 中转的一种实现）：

```
DSH 通道 => DSH 中转 | base: http://127.0.0.1:18902/v1 | model: openrouter/free
  DSH 调用: "dsh-ok"
```

> 不同反代插件暴露的模型名不同，以「拉取可用模型」的结果为准。
### 3.1 DeepSeek 官方 API Key

1. 去 <https://platform.deepseek.com/api_keys> 创建 Key
2. 扩展设置页 → 「模型通道」→ 填入 Key
3. 点「测试连通性」，显示「连通正常」即可

**模型选择**：`deepseek-flash` 支持图像理解且价格最低。

### 3.2 成本参考

总结一个 **25 分钟** 的中文视频（约 1.3 万输入 tokens + 1.3 千输出 tokens）：

- 输入（缓存未命中，空闲时段）：1 元 / 百万 tokens
- 输出（空闲时段）：4 元 / 百万 tokens
- 单次约 **0.018 元**，一天看 10 个视频约 **0.2 元**

## 四、用法

打开任意 `bilibili.com/video/BV...` 页面，右下角会出现一枚 **「AI 总结」** 浮层按钮：

- 点它 → 右侧浮出总结面板（面板默认不显示，不会遮挡视频）
- 面板右上角还有「看图」按钮，可在无字幕时抽帧做画面理解
- 播放器进入全屏或网页全屏时，面板会自动隐藏，不遮挡画面

> 按钮是独立的浮层，不注入 B 站工具栏，因此不影响页面任何布局。

工具栏图标点了可以快速总结当前视频或跳转设置。

## 五、目录结构

```
BiliAISummary/
├── manifest.json              # MV3 清单
├── src/
│   ├── background.js          # Service Worker：消息路由 / 缓存 / 编排
│   ├── lib/
│   │   ├── wbi.js             # B 站 WBI 签名（nav 取 key + 混排 + MD5）
│   │   ├── md5.js             # 纯 JS MD5
│   │   ├── bili.js            # 视频信息 / 字幕
│   │   ├── asr.js             # 无字幕时的语音识别兜底
│   │   ├── summarizer.js      # 分段 map-reduce 总结
│   │   ├── prompts.js         # 提示词模板
│   │   ├── llm.js             # 模型客户端（API / DSH 双通道）
│   │   └── store.js           # 设置与缓存
│   ├── content/               # 视频页面板
│   ├── offscreen/             # 音频解码（16k 单声道 WAV 切片）
│   ├── options/               # 设置页
│   └── popup/                 # 工具栏弹窗
```

## 六、技术要点

**字幕获取是四步级联**：`BVID → CID → WBI 签名调 /x/player/wbi/v2 → 拉 CDN 字幕 JSON`。
WBI 签名的关键是用 `nav` 接口拿 `img_key`/`sub_key`，按 64 位混排表重排后取前 32 位，
再对参数排序拼接后加盐 MD5 得 `w_rid`。实现在 `src/lib/wbi.js`。

**长视频用 map-reduce**：按 1.2 万字切块 → 3 并发分段提炼 → 汇总成文。
25 分钟视频 2 段，全流程约 5 秒。

**思考模式必须关**：`deepseek-flash` 默认开思考，会先烧 token 在 `reasoning_content` 上，
`max_tokens` 不够时正文为空。总结类任务统一发 `thinking: { type: 'disabled' }`。

字形、粗细、尺寸与原生完全一致。

## 六点五、三种深度的区别

三档**不是同一模板换个字数**，而是三套独立的结构。实测同一份 20 分钟字幕：

| 深度 | 输出结构 | 字数 | 耗时 |
|---|---|---|---|
| **快速** | 「值不值得看」+「讲了什么」（3 条内） | ~190 字 | 1.3s |
| **标准** | 一句话结论 / 核心观点 / 内容脉络 / 关键信息 / 适合谁看 / 避坑提示 | ~640 字 | 4.6s |
| **深度** | 标准版全部 + **核心观点带论证与例子** + 完整脉络 + 关键信息清单 + **争议与局限** | ~2200 字 | 11.5s |

## 七、已知限制

- 未登录 B 站的视频，或 UP 未上传字幕且未生成 AI 字幕的，需开 ASR 兜底（有成本）
- 付费课程 / 番剧 / 需大会员的视频取不到音轨
- B 站风控频繁时可能返回 -352，签名会自动刷新重试一次
